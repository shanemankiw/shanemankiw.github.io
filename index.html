Publications (highlighted research is in pale green; * equal contribution)

Flex-RSI: Benchmarking Recursive Self-Improvement of Frontier Agents

Jionghao Wang*, Jingdong Zhang*, Zhengming Yu, et al.
Tech Report 2026 / Project/ Blog/ GitHub/ Leaderboard

A budget-aware benchmark where agents rewrite their own harness between rounds to improve at a task. We ran 18 frontier models on 24 vision and robotics tasks to see where self-improvement pays off.

Steerable Humanoid Loco-Manipulation VLA

Jionghao Wang* (co-first author), et al.
In Submission

A humanoid policy steered by future goal images: a predictor turns subtask prompts into goal images, and a planner drives whole-body actions toward them across multi-task routines.

DiTaR: Disentangling Task-Relevant Latent Dynamics for Reward Modeling

Dayou Li*, Jionghao Wang*, Peihao Wang, Jiuzhou Lei, Hao Wang, Jichen Chai, Hezhen Hu, Minghui Zheng, Zhangyang Wang, Xin Li, Wenping Wang, Zhiwen Fan
arXiv 2026 / Paper/ Project/ GitHub

We learn dense rewards from action-free videos by modeling task-relevant latent dynamics, so the reward tracks task progress rather than visual distractors such as lighting.

Spatial-UMI-Dream: Scaling World Action Models with Metric Geometry for UMI Manipulation

Weiduo Yuan*, Ze Yuan*, Sihan Liu*, Jionghao Wang, Liang Heng, Zhenyu Zhao, Yue Wang
arXiv 2026 / Paper/ Project/ GitHub

A 5B spatial World Action Model pretrained on 605 hours of RGB-D UMI data to jointly predict future RGB, metric depth and actions, evaluated on RoboTwin-UMI, a twenty-task benchmark for UMI policy generalization.

Learning What Matters: Adaptive Information Theoretic Objectives for Robot Exploration

Youwei Yu, Jionghao Wang, Zhengming Yu, Wenping Wang, Lantao Liu
RSS 2026/ Paper/ Project/ GitHub

Developed QOED to enhance robot exploration by isolating identifiable model parameters and suppressing unidentifiable 'nuisance' directions in high-dimensional systems.

PDT: Point Distribution Transformation with Diffusion Models

Jionghao Wang*, Cheng Lin*, Yuan Liu, Rui Xu, Zhiyang Dou, Xiao-Xiao Long, Hao-Xiang Guo, Taku Komura, Wenping Wang, Xin Li
SIGGRAPH 2025 / Paper/ Project/ GitHub/ Twitter Post

PDT is a novel diffusion-based framework for transforming dense point distribution into a target distribution that is semantically meaningful.

Disentangled Clothed Avatar Generation from Text Descriptions

Jionghao Wang*, Yuan Liu*, Zhiyang Dou, Zhengming Yu, Yongqing Liang, Cheng Lin, Rong Xie, Li Song, Xin Li, Wenping Wang
ECCV 2024 / Paper/ Project/ GitHub

In this paper, we introduced a novel text-to-avatar generation method that separately generates the human body and the clothes and allows high-quality animation on the generated avatar.

360-Degree Panorama Generation from Few Unregistered NFoV Images

Jionghao Wang*, Ziyu Chen*, Jun Ling, Rong Xie, Li Song
ACM Multimedia 2023 / Paper/ GitHub/ Video

We proposed a novel diffusion-based pipeline that generates complete 360 panoramas using one or more unregistered NFoV images captured from arbitrary angles.

SPGen: Spherical Projection as Consistent and Flexible Representation for Single Image 3D Shape Generation

Jingdong Zhang, Weikai Chen, Yuan Liu, Jionghao Wang, Zhengming Yu, Zhuowen Shen, Bo Yang, Wenping Wang, Xin Li
SIGGRAPH Asia 2025 / Paper/ Project/ GitHub

SPGen leverages Spherical Projection (SP) to generate high-quality 3D shapes with diffusion models.
